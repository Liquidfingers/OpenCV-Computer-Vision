# OpenCV Computer Vision Project

## Overview
This project documents my practical learning and implementation of computer vision techniques using Python and OpenCV. It contains a Jupyter Notebook with image-processing exercises and the images used during development.

## Topics Covered
- Image loading and display
- Image resizing and rotation
- Drawing shapes and text on images
- HSV color conversion and color segmentation
- Image masks and bitwise operations
- Contour detection and hierarchy
- Contour area, perimeter, and centroid calculations
- Bounding boxes and basic shape classification

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

## Installation

Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebook and run the cells in order.

The purpose of this project is to develop practical skills in image processing, feature extraction, and basic computer vision using OpenCV.
